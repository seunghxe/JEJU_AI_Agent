# 최종 제출 패키지 확인사항

- [x] Python 3.12 환경에서 의존성 설치 및 Python 테스트 69개 통과.
- [x] UI 입력·차량 카드·연결상태 표시 검사 통과.
- [x] 제주데이터허브 4종을 휴대형 집계본으로 묶어 키 없이 로딩·추천 근거 재현.
- [x] 제출판은 `JEJU_DATAHUB_MODE=snapshot`으로 고정해 최초 실행 시 장시간 재수집 방지.
- [x] 평가용 API 키는 제출 ZIP의 `.env`에만 포함하고 공개 GitHub에서는 제외.
- [x] GitHub·데모 주소와 런타임 모델명을 최종 상태로 갱신.
- [x] 기존 충전망 분석과 이번 Agent 신규 구현 범위를 결과 설명자료에 구분.
- [x] 데이터·오픈소스·AI 개발 도구·한계를 별도 문서에 명시.

## 실행 시 알려진 제약

- 외부 API는 심사 환경의 인터넷 접속, 키 승인 상태, 제공처 쿼터에 따라 제한될 수 있으며 실패 시 저장자료·규칙 해석·직선거리로 전환합니다.
- 기본 지도는 Leaflet·OpenStreetMap이며 카카오 JavaScript 키가 설정된 경우에만 카카오 배경지도를 사용합니다.
- Windows에서는 Python 3.12 새 가상환경 사용을 권장하며 Python 3.14 가상환경을 재사용하지 않습니다.
- 평가용 키는 비용·호출 한도를 설정하고 심사 종료 후 폐기합니다.

## 이번 수정

데이터허브 설명은 API 사용 시 ‘연동됨 · 데이터 N종’, 동봉 자료 사용 시 ‘저장 자료 사용 · 데이터 N종’입니다. 수신·원본·매칭 수는 접힌 상세에 보존했습니다. v8 레이아웃과 추천 계산식은 유지하고 키 없는 집계 로더·검증 테스트를 추가했습니다. 실제 자료를 읽으므로 이전에 근거가 없던 후보의 순위가 달라질 수 있습니다.
