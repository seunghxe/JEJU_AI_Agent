## 이번 수정

데이터허브 설명은 API 사용 시 ‘연동됨 · 데이터 N종’, 동봉 자료 사용 시 ‘저장 자료 사용 · 데이터 N종’입니다. 수신·원본·매칭 수는 접힌 상세에 보존했습니다. v8 레이아웃과 추천 계산식은 유지하고 키 없는 집계 로더·검증 테스트를 추가했습니다. 실제 자료를 읽으므로 이전에 근거가 없던 후보의 순위가 달라질 수 있습니다.
