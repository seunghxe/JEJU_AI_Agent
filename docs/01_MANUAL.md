# 실행환경·사용자 매뉴얼

## 설치·실행

README의 Python 3.12 절차를 따릅니다. `.venv`를 다른 컴퓨터에서 복사하지 않습니다. `No module named dotenv`는 해당 Python에 python-dotenv 설치 여부를, pydantic-core/PyO3 오류는 Python 3.14 환경 재사용 여부를 확인합니다. 외부 API 호출 중심이므로 로컬 GPU 모델을 설치하지 않습니다. 센터 PC 자체 실행은 미검증입니다.

## 키 설정

최종 제출 ZIP에는 심사 실행용 `.env`가 포함되어 있으므로 그대로 실행할 수 있습니다. `.env`가 없는 공개 GitHub판에서는 `.env.example`을 `.env`로 복사한 뒤 본인이 발급받은 키를 입력합니다. 기존 `.env`를 덮어쓰지 않으며 수정 후 서버를 재시작합니다. 평가용 키는 공개 저장소에 올리지 않고 심사 종료 후 폐기합니다.

| 제공처 | 절차 | 변수 |
|---|---|---|
| Google AI Studio https://aistudio.google.com/ | 본인 프로젝트 API 키 발급, 모델·할당량 확인 | GEMINI_API_KEY, GEMINI_MODEL |
| Kakao Developers https://developers.kakao.com/ | 앱·서비스 설정 후 REST 키 확인 | KAKAO_REST_API_KEY |
| Kakao Mobility https://developers.kakaomobility.com/ | 자동차 길찾기 권한·적용 키 확인 | KAKAO_REST_API_KEY |
| 카카오 지도 | JavaScript 키·지도 사용 설정, SDK 허용 도메인 등록 | KAKAO_MAP_JS_KEY |
| 공공데이터포털 https://www.data.go.kr/ | 한국환경공단 전기자동차 충전소 정보 활용 신청·승인, Decoding 인증키 확인 | DATA_GO_KR_SERVICE_KEY |
| 제주데이터허브 https://jejudatahub.net/ | 프로젝트 생성 → 자료 담기 → 프로젝트 키 → 자료별 API 코드 확인 | JEJU_DATAHUB_PROJECT_KEY와 네 *_CODE |

카카오 지도에는 `http://localhost:8501` 및 실제 사용하는 배포 도메인을 등록합니다. REST 키와 JS 키는 다릅니다. 제공처 화면·발급 절차는 변경될 수 있습니다. 403은 승인·접근조건·키를 확인하고, 500은 기간·요청 형식·제공처 장애를 구분하되 코드만으로 원인을 단정하지 않습니다. 문의 시 키가 포함된 요청 URL을 공유하지 않습니다.

## 데이터허브 확인

처음 실행하고 키·코드가 없으면 제출판의 hub_snapshot.json을 바로 읽습니다. 기존 `.env`에 키가 있어도 내려받지 않으려면 JEJU_DATAHUB_MODE=snapshot으로 설정하세요. 상태는 ‘저장 자료 사용’으로 구분됩니다. auto 모드에서 키·코드를 설정하거나 api 모드를 사용하면 API 조회 경로로 동작합니다. 최초 수집은 여러 페이지 호출이 필요하고 완료 집계는 `.hub-cache`에 재사용됩니다. ‘제주데이터허브 점검’은 snapshot에서는 파일 재검증, API 모드에서는 캐시 사용 가능한 점검입니다. 강제 다운로드 버튼이 아닙니다.

허브 집계 카탈로그 해시가 다르거나 수치·매칭 검증에 실패하면 해당 스냅샷 전체를 제외하고 오류를 표시합니다. 임의로 시설 CSV와 집계 파일을 섞지 마세요. `python jeju_hub_check.py`로 상태·행·매칭 진단을 볼 수 있습니다.

## 사용 순서

1. 내 차: 차종·규격·배터리·출발지 설정. 기기 위치 사용은 브라우저 허용 필요.
2. 추천 기준: 별도로 펼쳐 균형/이동시간/대기 위험/Plan B 선택.
3. 요청: 장소와 조건 입력. 여러 줄 가능, 전송 후 입력창 비움. 원문은 ‘내 요청 보기’에 보존.
4. 진행 상태: 질문 이해·장소 찾기·비교·실시간·Plan B·답변 단계 확인.
5. 결과: A의 이동 기준은 출발지 입력 시 출발지, 없으면 목적지. B는 A에서의 거리·시간.
6. 지도: 군집 숫자 클릭 확대, 개별 점 클릭 시설 정보와 길찾기.
7. 후속 요청: ‘Plan A 빼고 다시’, ‘배터리 20%야’. 같은 이름의 장소가 여러 곳이면 주소 후보를 선택하고, 찾지 못하면 지역·지점명을 보충.
8. 길찾기: 사용자 클릭으로 카카오맵 연결. 예약·결제·자동 차량 제어는 없음.
9. 최근 계획·자주 가는 곳: 브라우저 로컬 저장소 사용. 공용 PC 사용 후 사이트 데이터를 삭제.

## 오류·제약

실시간 꺼짐은 키 미설정/실패로 과거 자료 모드임을 뜻합니다. 허브 일부 연동은 접힌 상세에서 확인합니다. 연결 성공이라도 특정 시설에 자료가 없을 수 있습니다. 차량경로 미확인은 직선거리를 도로시간으로 바꿔 해석하면 안 됩니다. 장소 질문에는 지점·주소를 보충합니다. 모바일 위치는 HTTPS·권한을 확인하거나 수동 출발지로 대체합니다.

서버 재시작 시 대화 기억은 사라집니다. 브라우저는 약 60초마다 상태를 점검하지만 서버는 5분 실시간 캐시를 사용할 수 있습니다. 즉각적 만차 감지·백그라운드 내비게이션·도착 시 충전 가능 보장이 아닙니다. 주행 추정은 날씨·경사·우회를 반영하지 않습니다. 지도·차량 사진은 외부 네트워크가 필요합니다.
